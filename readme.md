## 📦 Proje Hakkında

Bu depo, **Ruti Medya** için hazırlanmış video indirme API servisinin kaynak dosyalarını içerir.

API; YouTube, Instagram, TikTok, Facebook, Twitter/X ve benzeri platformlardan gelen medya bağlantılarını işlemek, video bilgilerini çözümlemek ve Ruti Medya üzerindeki video indirme sistemlerinde kullanılmak üzere geliştirilmiştir.
